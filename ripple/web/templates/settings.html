Ask Ripple

Draft around a cut

When a scene is omitted, Ripple proposes text patches to the neighbouring scenes in the same turn. Every patch is gated behind Confirm like any other edit. Report only computes the orphaned references and stops there.

Show the plan before drafting

The coverage list and per-scene intentions render in chat before any drafting spend. Turning this off drafts immediately and still gates on Confirm.

Tool call ceiling per turn

Caps model-directed calls inside one turn, on top of the global token budget.

Keep conversations per script

Conversations persist beside question history. Pending change sets from an abandoned conversation are rejected on close.

Confidence floor for proposed facts

A fact the judge scores below the floor is held back from the proposal and named on the card, so a doubtful change is reported rather than offered. Off proposes everything the judge accepts.
